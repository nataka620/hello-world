# リアルタイム音声AI会話 & 要約ツール

ブラウザから話しかけると、次の3つが同時にリアルタイムで進行するツールです。

- **時間無制限の音声文字起こし** — ブラウザの Web Speech API を使い、認識が自動で途切れても即座に再開し続けるので、長時間の会話でも止まりません。
- **AIとの会話** — 話した内容ごとに Claude (Sonnet 5) が応答を生成し、ストリーミング表示 + 音声合成で読み上げます。
- **AIによるリアルタイム要約** — Claude (Haiku 4.5) が会話の内容を要約し続けます。要約は一定量たまるごとに更新され、直近の会話だけをモデルに渡す設計なので、どれだけ長く話しても入力トークン量が際限なく増えることはありません。

## セットアップ

```bash
npm install
cp .env.example .env
# .env に ANTHROPIC_API_KEY を設定 (または `ant auth login` 済みならそのままでOK)
npm start
```

`http://localhost:3000` をブラウザ (Google Chrome / Microsoft Edge 推奨) で開いてください。Web Speech API を利用するため、音声認識にはこれらのChromium系ブラウザが必要です。

## 使い方

1. 「会話を始める」ボタンでマイクを開始
2. 話した内容がリアルタイムで文字起こしされ、AIが応答（テキスト表示 + 読み上げ）
3. 画面右側に会話の要約が自動で更新され続ける
4. 「会話をクリア」でリセット、言語や読み上げのON/OFFも切り替え可能

## 仕組み

- フロントエンド (`public/`) はプレーンな HTML/CSS/JS で、`SpeechRecognition` により継続的に音声認識を行い、認識が止まったら自動再開することで実質的に時間無制限の文字起こしを実現しています。
- バックエンド (`server.js`) は Express + WebSocket サーバーで、確定した発話を Anthropic API に送信し、応答をストリーミングで返します。
- 会話履歴は直近のやり取りのみをモデルに渡し、それより前の内容は要約としてバックグラウンドで畳み込むことで、セッションが長時間続いてもリクエストサイズが膨張しないようにしています。
